# 小小遊樂園

給幼兒使用的手機版小遊戲入口。純 HTML、CSS、JavaScript，沒有登入、後端或資料儲存。

## 專案結構與新增遊戲

- `index.html`、`home.css`：入口首頁與排版。
- `home.js`：遊戲清單，新增遊戲時在 `games` 陣列加入名稱、介紹、連結和插圖。
- `games/dentist/index.html`：牙醫遊戲頁面。
- `styles.css`、`game.js`：牙醫遊戲外觀與互動。
- `images/`：首頁的遊戲插圖。

下一款遊戲可放在 `games/<遊戲名稱>/index.html`，並提供回到 `../../index.html` 的連結。完成後加入首頁清單即可。

## 小小廚師

- 披薩與蛋糕兩種料理。加料自動鋪成造型，裝飾保留拖放位置。
- 蛋糕同一組夾心可放多種料，每次加入完整鋪滿並向上堆疊，拖入蛋糕層才蓋上並開始下一層；不會自動加入白色夾層。夾心包含：香草、草莓、巧克力夾心、布丁、水蜜桃丁、橘子丁與葡萄丁，亦可增加蛋糕層。
- 蛋糕裝飾包含草莓、藍莓、奶油花、蠟燭、巧克力、糖粒、橘子瓣、單顆綠葡萄與单顆棉花糖。棉花糖分成白色、粉紅、紫色與薄荷色四格。
- 手機橫放時左右並排，料理保持可見，食材區可獨立滑動；直放仍可遊玩。
- 可照圖示訂單料理、撤銷食材或重新做。上菜後可下载 960 × 720 的圖片。

## 寵物洗澡店

- 狗、貓、兔子、小鳥、紅鶴、斑馬、熊貓、大象與狐狸九位小客人，具各自的造型與清洗輪廓。
- 泥污、泡沫和濕潤水光依實際寵物輪廓裁切，均勻涵蓋身體、耳朵與腳掌，保留眼睛與嘴巴。泥污以柔和斑駁材質呈現，泡沫包含不同大小的氣泡與高光，水滴搭配濕潤光澤。拖曳海綿時清潔區域立即起泡，再逐區沖掉泡泡及吹乾水分。
- 完成前一階段才會開啟下一工具；點一下不會完成清潔。
- 最後可選三色蝴蝶結、領巾、花朵、雛菊、皇冠、禮帽、眼鏡或圍巾，搭配一個頭飾、一副眼鏡及一個胸前配件。依圈圈位置拖放，再按「打扮好了」完成。

小小廚師與寵物洗澡店使用 `games/play.css`、`games/play.js` 的共用介面與拖曳功能，各遊戲邏輯位於自己的資料夾。

## 造型遊戲操作

- 八個主分類：臉形、頭髮、眉毛、眼睛、鼻子、嘴巴、耳朵及穿著。穿著分為衣服、褲子、套裝與鞋子；套裝包含完整的吊帶褲、吊帶短褲、小洋裝、公主洋裝及連身服，不再依賴分開挑選的上下衣。鞋子有運動鞋、靴子、娃娃鞋、涼鞋、拖鞋及光腳，可獨立選顏色。
- 各分類提供多種樣式及預設色票，也可用自選顏色。套裝顏色同時套用到整套服裝，分開搭配時衣服與褲子可獨立調色。
- 手機更換五官時會放大看臉，挑衣服時看全身，也可手動切換預覽。
- 可隨機搭配、重新開始，或下載 720 × 1020 的 PNG 圖片。
- 造型使用 localStorage 保留在同一個瀏覽器；瀏覽器不允許儲存時仍可遊玩。
- 所有角色與服裝都由 SVG 元件組成，無外部圖片或帳號需求。
- 程式與排版位於 `games/stylist/`，首頁插圖位於 `images/stylist.svg`。

## 牙醫遊戲操作

每位病人有兩顆需要治療的牙齒，問題獨立隨機抽選，可以重複。每顆牙齒保留自己的治療進度，兩顆全部治好才完成回合。

- 刷牙：拖曳牙刷來回刷遍整顆黃牙。
- 夾菜渣：夾住菜渣，拖曳到垃圾桶後放開；放錯位置會回到牙齒上。
- 補牙：清除全部黑色蛀牙，再用填補器把藍色洞洞補白。
- 支援滑鼠與手機觸控。

## 本機開啟

在此資料夾執行：

```bash
python3 -m http.server 8080
```

前往 `http://localhost:8080`。也可以直接開啟 `index.html`；直接用檔案方式開啟時，遊戲連結需開啟 `games/dentist/index.html`。

## GitHub Pages

網站使用 `main` 分支根目錄部署。提交更新到 `main` 後，GitHub Pages 會自動重新發布。所有連結皆使用相對路徑，支援 repository 子路徑。
