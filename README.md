# 小小牙醫診所

給幼兒使用的手機版牙醫拖曳遊戲。純 HTML、CSS、JavaScript，沒有登入、後端或資料儲存。

## 線上遊玩

https://bomb1751.github.io/dentist-game/

## 遊戲操作

每位病人會有兩顆需要治療的牙齒。兩個問題獨立隨機抽選，可以是相同類型；兩顆全部治好才會完成這一回合。每顆牙齒會保留自己的清潔與填補進度。

- 刷牙：拖曳牙刷來回刷遍整顆黃牙，刷過的地方會逐漸變白。
- 夾菜渣：用小夾子夾住菜渣，拖曳到旁邊的垃圾桶後放開；放錯位置會回到牙齒上。
- 補牙：先用清蛀牙器清除全部黑色部分，再換填補器把藍色洞洞補白。
- 支援滑鼠與手機觸控。可直接從工具箱拖曳工具，也可以先選工具再在牙齒上拖曳。

## 本機開啟

直接開啟 `index.html`，或在此資料夾執行任一靜態檔案伺服器：

```bash
python3 -m http.server 8080
```

然後前往 `http://localhost:8080`。

## GitHub Pages

網站使用 `main` 分支根目錄部署。更新 `index.html`、`styles.css` 或 `game.js` 並提交到 `main` 後，GitHub Pages 會自動重新發布。

所有檔案皆使用相對路徑，可部署在 GitHub Pages 的子路徑。
